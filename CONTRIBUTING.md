## Code Style

In this project, we preserve indentation on empty lines.

The indentations make it easier to read the code and allow for interactive testing of functions.
Therefore:

* `ruff-format` is not used. 
* The `trailing-whitespace` pre-commit hook is disabled.
* Both changes have been documented in .pre-commit-config.yaml. 
* Contributors should avoid removing indentation from intentionally indented blank lines.
